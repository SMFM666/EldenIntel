ELDENINTEL PORTABLE - WINDOWS X64

1. Extract the entire ZIP to a normal folder.
2. Keep assets, native, and TwitchRelay beside EldenIntel.exe.
3. Run Elden Ring offline with Easy Anti-Cheat disabled.
4. Start EldenIntel.exe.

Do not run EldenIntel directly from inside the ZIP.

The bundled .NET runtime means no separate .NET installation is required.
The optional 32:9 UI fixes require Mod Engine 3 Manager and are installed into
the active Elden Ring profile reported by its manager_settings.json file.

Clone summons require the matching EldenIntel Mod Engine package. The game's
regulation file is not redistributed in this public archive.

These tools directly interact with the running game. Use them only offline.
Back up saves before using game-modification tools. Online/EAC-enabled use is
unsupported and may result in a ban.
