ELDENINTEL SUMMON RUNTIME

This folder contains EldenIntel's isolated regulation overlay. It does not
replace the base game's regulation.bin.

Launch Elden Ring with:
D:\SteamLibrary\steamapps\common\ELDEN RING\Game\launchmod_eldenintel.bat

The overlay supplies the private player-clone NpcParam, NpcThinkParam,
BuddyParam, and BuddyStoneParam rows generated by Spirit Battler.
